## Tujuan dan input

Menguji kemampuan bridge aktual sebelum membangun pengiriman bisnis.

Pemilik menentukan nomor bisnis dan nomor uji, lalu melakukan pairing. Pengiriman tahap ini hanya ke tujuan uji yang telah disetujui. Backlog lokal mencatat nomor uji 082165443677. Pastikan pemilik mengonfirmasi tujuan ketika uji dijalankan.

## Bukti dan catatan progres

Pada 5 November 2026, pairing web berjalan lewat `http://127.0.0.1:5173`, API backend lewat port `3000`, dan bridge lewat port `3001`. Status pairing pernah `connected`, QR hilang setelah pairing, dan satu PDF sintetis dikirim ke nomor uji `082165443677` melalui `POST /whatsapp/send-synthetic-pdf` dengan HTTP `200`. Source mengirim nama `nota-sintetis-synectra.pdf`, tipe `document`, dan file lokal `apps/server/.tmp/synthetic-nota.pdf`. Response transport mengonfirmasi pengiriman sukses dengan response runtime. Receipt delivered/read belum tersedia karena health bridge Baileys melaporkan `sendReadReceipts: false`. Restart server memulihkan route ke status `connected`; pemeriksaan sesi menemukan `creds.json` dan 1090 file sesi.

Penguatan arsitektur dan kontrol akses selesai:
1. Route `/whatsapp/*` diproteksi guard owner (`WHATSAPP_OWNER_KEY` atau Origin allowlist `http://127.0.0.1:5173` / `http://localhost:5173`). Request dari origin asing ditolak 401/403.
2. Validasi input nomor telepon ketat (`0\d{9,14}`) diterapkan di boundary presentation dan application.
3. Timeout request `sendMedia` dibatasi 15 detik dengan penanganan status ambigu (`deliveryStatus: 'unknown'`).
4. Schema contracts diperluas dengan field `deliveryStatus`, `fileName`, dan `mimeType` agar transparan terhadap status pengiriman.
5. Composition root memisahkan dependensi bridge di `main.ts`, mencegah collision port pada automated testing.

Validasi proyek: `pnpm test`, `pnpm typecheck`, `pnpm build`, dan `pnpm architecture` (22 modules, 27 dependencies, 0 violation) lulus 100%.

Catatan status: Karena bridge Baileys upstream tidak menyediakan callback delivered/read receipt ke endpoint `/send-media` dan verifikasi visual tanda terima fisik pada perangkat belum dapat dilakukan tanpa receipt, T03 diselesaikan pada level implementasi teknis dan tetap ditandai `review` hingga diverifikasi pemilik atau dilanjutkan pada T19/T20.

Acuan planning bagian 3.3, 6.1–6.2, 6.5, 13 fase 0.
