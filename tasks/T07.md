## Bukti dan catatan progres

Status `done`. Draft dan penerbitan nota tersimpan di Firestore owner-scoped serta didukung in-memory store dengan idempotensi selaras. Automated test suite pada `apps/server/test/invoice.test.ts` memverifikasi:
1. Perhitungan rupiah integer dan penerbitan nomor nota atomik (`INV-YYYYMM-000001`).
2. Penolakan update draft stale (`Conflict: stale invoice version`) dan penyimpanan snapshot revisi immutable.
3. Penanganan atomisitas penerbitan berurutan dan penegakan idempotency key (retry menghasilkan nota identik tanpa memajukan nomor sequence).
4. Isolasi ketat data nota antarpemilik (owner-scoped).
5. Route HTTP API lengkap (`POST /api/invoices`, `PUT /api/invoices/:id`, `POST /api/invoices/:id/issue`) dengan response HTTP 409 pada konflik versi atau nota non-draft.

Seluruh server test lulus (27/27 pass) dan typecheck TypeScript monorepo bersih (`pnpm -r typecheck`).
