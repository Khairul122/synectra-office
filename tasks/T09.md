## Tujuan dan input

Menghasilkan PDF bertanda tangan yang sesuai invoice referensi dan snapshot final.

Pemilik menyediakan tanda tangan asli atau meninjau ekstraksi dari PDF lama.

## Langkah kerja

- [x] Implementasikan unggah PNG transparan, validasi ukuran/magic bytes, dan versi aset.
- [x] Buat template A4 dengan detail invoice, ledger, total, catatan persetujuan, dan blok tanda tangan.
- [x] Render menggunakan Chromium headless terkontrol, escaping teks, dan network disabled.
- [x] Simpan PDF pada filesystem privat dan metadata/checksum di Firestore. Tulis temporary file lalu atomic rename sebelum status ready.
- [x] Tangani penulisan file gagal dan artefak yatim melalui cleanup rollback serta rekonsiliasi metadata/disk.
- [x] Gunakan filesystem privat untuk versi signature dan cegah QR, credential, atau signature mentah masuk log.

## Kriteria selesai

- [x] PDF memuat signature yang disetujui, tanpa deadline, dan nominal sesuai snapshot.
- [x] Judul panjang serta 30 baris pembayaran tetap terbaca melalui test PDF.
- [x] Aset ready menunjuk file yang ada dan hash sesuai; rekonsiliasi menghapus metadata yatim/checksum-invalid.
- [x] Versi signature dapat ditelusuri dan PDF menyimpan `signatureAssetId`.

## Bukti dan catatan progres

Status review. Implementasi dan test lokal selesai. Browser smoke test/screenshot belum tersedia karena Chrome DevTools MCP tidak terkonfigurasi. Firestore production-write smoke test belum dijalankan karena environment credential aktif tidak tersedia.

Bukti lokal: `pnpm typecheck`, `pnpm test`, dan `pnpm build` lulus. `apps/server/test/pdf.test.ts` mencakup PDF normal, judul panjang, 30 payment rows, checksum, owner isolation, signature versioning, dan rekonsiliasi artefak yatim.
