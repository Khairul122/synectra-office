## Bukti dan catatan progres

1. **DPR Clamping**:
   - `scene-manager-2d.ts` mengimplementasikan pembatasan DPR: `this.ratio = this.economy ? Math.min(1, dpr) : Math.min(1.5, dpr);`.
   - Mengurangi alokasi memori canvas buffer drastis pada layar HiDPI / Retina (>2x).

2. **Frame Pacing & Tab Visibility**:
   - Scene 2D mematikan requestAnimationFrame dan membersihkan timer saat tab tidak aktif (`document.hidden`).
   - Mode tenang (quiet pacing) throttling ~10 FPS (`setTimeout(..., 100)`) untuk menghemat konsumsi CPU/GPU saat tidak ada aktivitas avatar/animasi.

3. **Layout Responsif Mobile (<=760px)**:
   - Media query `@media(max-width:760px)` di `office.css`: scene compact 170px (`flex:0 0 170px; height:170px;`) di bagian atas, dan drawer detail form mengambil sisa layar penuh (`flex:1 1 auto; overflow-y:auto;`) saat drawer dibuka (`.office-workspace.has-drawer`).
   - Elemen scene overlay chrome disembunyikan agar tidak menutupi tampilan compact canvas.

4. **Aksesibilitas & Focus Trap**:
   - Drawer di `OfficeSpikeView.tsx` memiliki atribut modal WAI-ARIA (`role="dialog" aria-modal="true" aria-labelledby="drawer-title"`).
   - Trap fokus Tab/Shift+Tab bersiklus di dalam elemen drawer dan penutupan melalui tombol `Escape`.
   - CSS mendukung `prefers-reduced-motion: reduce` (mematikan transisi/animasi) dan `:focus-visible` dengan outline jelas.

5. **Fallback Panel HTML Interaktif**:
   - Menampilkan status operasional real-time (Server, WhatsApp, Work State), 6 aksi bisnis langsung (Nota, Kanban, WhatsApp, Kalender, Arsip, Printer), daftar ruangan, dan tombol reload kanvas visual jika terjadi kegagalan render kanvas.

6. **Verifikasi Test Suite**:
   - Lolos seluruh 6 test unit/integrasi pada `apps/web/test/office-performance-accessibility.test.mjs`.
