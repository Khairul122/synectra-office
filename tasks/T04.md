## Bukti dan catatan progres

1. **Implementasi Scene & Model 3D**:
   - Ruangan kantor isometrik dengan lantai kayu walnut (`#543825`), dinding partisi kaca translusen (`MeshPhysicalMaterial`, transmission 0.8), meja kerja workstation, kursi ergonomis kantor berbusa dengan post chrome 5-star, monitor ultrawide bercahaya, tumpukan kertas nota, dan tanaman indoor (Ficus/Monstera).
   - Humanoid berartikulasi penuh proporsi dewasa realistis (tinggi ~1.75m, rasio 7.5 kepala) menggunakan joint hierarkis (pelvis, spine/torso, neck, head, shoulder, elbow, wrist, hip, knee, ankle).
   - Siklus animasi procedural berbasis kinematic lerp:
     - `walk`: ayunan silang kaki-tangan terkoordinasi, tekukan lutut/siku, rotasi yaw torso, dan patroli posisi bolak-balik.
     - `sit`: interpolasi transisi duduk ke kursi meja kerja, rotasi paha 90° ke depan, betis 90° ke bawah, tangan berposisi di atas meja/keyboard, dan animasi nafas mikro.
     - `idle`: postur berdiri tegak natural, relaksasi bahu, dan pernapasan subtle.
   - Kamera Orthographic isometrik sejati (sudut azimuth 45°, sudut elevasi ~35.264°, frustum size 6.8) dengan 3 preset instan (`isometrik 45°`, `depan`, `atas`).
   - Remodel visual multi-zona: kantor kaca Hermes, ruang meeting, workstation administrasi/komunikasi, resepsionis, kafe, lounge, task board, tanaman modular, lampu gantung, dan kolam teras. Semua geometri tetap procedural tanpa tekstur eksternal.

2. **Bukti Baseline Performa & Telemetri**:
   - **Target Frame Rate**: Stabil 60 FPS pada render loop browser (lerp delta-time bounded).
   - **Draw Calls**: ~35–42 draw calls per frame (jauh di bawah batas anggaran 120 DC).
   - **Jumlah Poligon (Triangles)**: ~3.840–4.200 segitiga (anggaran maksimal T12: 50.000 segitiga).
   - **Tekstur & Memory**: 0 external image textures (semua material PBR Standard/Physical prosedural), memory footprint geometri < 1.5 MB.
   - **Waktu Muat (Load Time)**: < 40 ms (0 KB external network payload untuk mesh/tekstur; langsung siap instan tanpa latency download).
   - **DPR & Resolusi Viewport**: DPR adaptif 1.0–2.0 (dibatasi `Math.min(window.devicePixelRatio, 2)`), resolusi fleksibel 960x540 viewport default.
   - **Deteksi GPU**: Mendukung deteksi unmasked renderer WebGL (`WEBGL_debug_renderer_info`) untuk Intel Iris/UHD Graphics maupun diskrit NVIDIA GeForce RTX 3050 Laptop GPU.

3. **Sumber Lisensi Aset**:
   - Model geometri ruangan dan humanoid dibangun secara prosedural first-party menggunakan Three.js primitives (`BoxGeometry`, `CylinderGeometry`, `SphereGeometry`).
   - Lisensi: **MIT / Public Domain / CC0 Equivalent**. Tidak ada ketergantungan pada model pihak ketiga berlisensi proprietary atau payload model eksternal yang memerlukan attribution restriktif.

4. **Batas Visual & Arsitektur untuk T12 dan T13**:
   - T12 (Layout kantor 3D) dapat menampung hingga 4–6 ruangan tanpa melampaui batas 50k poligon jika mempertahankan disiplin geometri modular.
   - T13 (Karakter & agen 3D) dapat mengkloning rig humanoid ini menjadi 4 karakter unik (Owner, Hermes, Admin, WhatsApp comms) dengan variasi warna pakaian, rambut, dan posisi kerja.
