## Tujuan dan input

Menjadikan Hermes lead yang dapat menyiapkan pekerjaan melalui API bisnis tervalidasi.

Scope profil dan batas biaya harus ditetapkan sebelum otonomi bisnis.

## Langkah kerja

- [x] Hubungkan chat dan session profil kantor melalui capability yang terverifikasi.
- [x] Implementasikan tool scoped untuk cari klien, draft nota, preview, payment list, dan prepare delivery.
- [x] Terapkan pemeriksaan sesi aplikasi atau credential agent scoped, actor, owner dan operasi pada backend. Admin SDK Firestore memakai IAM server sehingga pemeriksaan owner tetap wajib.
- [x] Pisahkan data dokumen/pesan klien dari instruksi tool dan batasi akses shell/credential host.
- [x] Tampilkan progress tool, hasil, error, usage yang tersedia, serta event untuk karakter Hermes.
- [x] Buktikan penerbitan final nota, verifikasi payment, serta pengiriman mengikuti approval pemilik.

## Kriteria selesai

- [x] Hermes membuat draft nota dari permintaan pemilik melalui tool.
- [x] Agent gagal memverifikasi payment atau mengirim tanpa approval yang sah.
- [x] Konten klien yang memuat instruksi tidak memperluas izin.
- [x] Session, profil, error, dan biaya yang tersedia dapat ditelusuri.

## Bukti dan catatan progres

Status done per 8 November 2026.
Implementasi modul Hermes:
1. Kontrak Zod (`HermesSession`, `HermesMessage`, `HermesToolCall`, `HermesUsage`) di `packages/contracts`.
