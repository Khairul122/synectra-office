## Bukti dan catatan progres

### Implementasi & Test Suite
1. **Backup & Restore Service (`apps/server/src/modules/backup/application/backup-service.ts`)**:
   - `createOwnerBackup`: Mengharuskan worker dalam kondisi tenang (`isWorkerQuiescent()`), mengekstrak metadata dokumen Firestore (clients, categories, invoices, payments, deliveries, signatures), menyalin file privat lokal (PDF dan gambar signature), dan menghitung SHA-256 manifest per file serta seluruh paket.
   - `verifyAndRestoreBackup`: Memverifikasi integritas setiap file dengan SHA-256 manifest, menolak file rusak/dimanipulasi (tampered), memvalidasi skema payload, dan memulihkan metadata serta file ke target direktori secara konsisten.
   - Kontrol worker tenang (`setWorkerQuiescent`, `isWorkerQuiescent`) menjamin snapshot tidak dilakukan saat ada pengiriman atau transaksi berjalan.
2. **Comprehensive Test Suite (`apps/server/test/resilience-and-backup.test.ts`)**:
   - `T20-1`: Akses negatif ditolak: session expired (401), missing/invalid CSRF token (403), IDOR antar owner (404, tidak bocor), sanitasi path traversal pada private file storage, validasi skema firestore rules, dan masking secret pada logger Fastify.
   - `T20-2`: Delivery worker resilience: proteksi concurrent lease, fencing token UUID, crash sebelum send (status tetap sending sampai lease expired), crash setelah send (status `unknown` masuk antrean rekonsiliasi tanpa blind retry resend), dan invalidasi approval otomatis jika payload/PDF hash berubah.
   - `T20-3`: Kegagalan penulisan PDF tidak meninggalkan artefak yatim di storage lokal.
   - `T20-4`: Mitigasi prompt injection Hermes: menolak instruksi jahat (akses shell, credential host), membatasi tool dispatch deklaratif sesuai Zod enum dan owner scoping (`actorId === ownerId`), serta menolak aksi sensitif finansial tanpa approval.
   - `T20-5`: Integritas finansial & concurrency: proteksi optimistic concurrency pada issuing invoice melalui `expectedVersion`, pelacakan saldo rupiah, serta pembatalan verifikasi (payment reversal) mengembalikan sisa tagihan secara utuh.
   - `T20-6`: Backup & restore ber-manifest SHA-256 menolak pencadangan saat worker aktif, mendeteksi manifest tampering, dan memulihkan seluruh data dan referensi file secara konsisten.
